ПОВІТРЯНА ВАРТА — Android-приложение (оболочка сайта)

Адрес: https://radar.povitryanavarta.pp.ua/

КАК СОБРАТЬ APK:
1. Установить Android Studio на компьютер (современная версия, с Android SDK 35).
2. Распаковать этот архив.
3. Android Studio -> Open -> выбрать папку PovitryanaVartaAndroid.
4. Дождаться Gradle Sync. Для первой сборки потребуется интернет.
5. Build -> Build App Bundle(s) / APK(s) -> Build APK(s).
6. Файл: app/build/outputs/apk/debug/app-debug.apk.
7. Перенести APK на Android и установить.

ОСОБЕННОСТИ:
- Настоящий сайт открывается в WebView, нужен интернет.
- JavaScript, cookies и localStorage включены.
- Скриншоты PNG через ссылки download blob:/data: сохраняются в Галерею на Android 10+.
- Если сайт использует другой способ создания PNG, понадобится доработка обработчика.
- Сторонние ссылки открываются во внешнем браузере.
- Нужен Android 6.0+, рекомендуем Android 10+.

ВАЖНО: Это проект для сборки, а не готовый APK. На текущем сервере нет Android SDK и Gradle, поэтому сборка здесь не выполнялась и приложение не проверено на устройстве.
Сайт является неофициальным источником информации о воздушных угрозах, ориентируйтесь на официальные оповещения.
